# MindForge Design System

## 🎨 Paleta de Colores

### Base (Zen + Profesional)
- **Background:** `#FAFAFA` (blanco roto, sin distracciones)
- **Text Dark:** `#1F2937` (gris oscuro, legible)
- **Border:** `#E5E7EB` (gris muy claro)

### Primario (Confianza)
- **Primary:** `#1E40AF` (azul profundo, empresarial)

### Secundario (Balance)
- **Secondary:** `#0F766E` (teal, calma + energía)

### Accent (Motivación)
- **Accent:** `#EA580C` (naranja, celebración)
- **Success:** `#10B981` (verde, feedback positivo)
- **Error:** `#EF4444` (rojo, feedback negativo)
